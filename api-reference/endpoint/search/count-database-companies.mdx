## Use Case:
Count matching cached companies before running a database company search.

## Pricing
This endpoint is free — it does not incur any charges.

## Filtering by technology
`technologies` works as on [database company search](/api-reference/endpoint/search/database-companies#filtering-by-technology): names from [List technologies](/api-reference/endpoint/search/technologies), written exactly as listed. Counting first is a free way to check that a name matches the companies you expect.
